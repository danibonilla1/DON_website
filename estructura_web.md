## 9. Preguntas Frecuentes (FAQ) - Tono Personal
1. **¿Qué pasa si la entrega se retrasa?** -> Paciencia, creatividad, entrega episódica.
2. **¿Cuál es la diferencia con YouTube?** -> Experiencia completa vs fragmentos, sin anuncios.
3. **¿Cómo sé si es para mí?** -> Si resonaste con los vídeos, si buscas conexión profunda.
4. **¿Hay garantía de devolución?** -> No (salvo causa mayor), basado en confianza mutua ("Confía en tu creador").
5. **¿Qué significa "Entrega Periódica"?** -> Capítulo a capítulo, vivir la historia en tiempo real.

## Notas Técnicas para IA Implementadora
- El precio se actualiza dinámicamente en el enlace de Gumroad usando JavaScript (`modals.js`).
- El diseño es responsive: en móvil el libro 3D se ubica encima del contenido de la tarjeta.
- Los badges de confianza usan `flex-wrap: nowrap` en móvil para mantenerse en una línea.
- Las animaciones 3D son CSS puro (`transform-style: preserve-3d`).
